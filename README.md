## Карта регистров (база 0x7000_0000)
| Смещение | Доступ | Регистр | Содержимое                             |
|----------+--------+---------+----------------------------------------|
| 0x00     | R      | STATE   | [15:0] светофор A, [31:16] светофора B |
| 0x04     | W      | CTRL    | бит 0 = NEXT (1 переводит в след сост) |

Лампы: бит 0 = красный, бит 1 = желтый, бит 2 = зеленый.

## Последовательность состояний (A и B)
0: A=Красный, B=Красный (0x00010001)
1: A=Красный+Желтый, B=Красный (0x00010003)
2: A=Зеленый, B=Красный (0x00010004)
3: A=Желтый, B=Красный (0x00010002)
4: A=Красный, B=Красный+Желтый (0x00030001)
5: A=Красный, B=Зеленый (0x00040001)
6: A=Красный, B=Желтый (0x00020001)
